# LipaGo

LipaGo is an Android mobile application designed to help users discover tourist destinations in Lipa City, Batangas.

## Project Overview

The application provides information about selected tourist destinations and allows users to create an account and log in using Firebase Authentication.

## Features

- User Registration
- User Login and Logout
- User Dashboard
- Tourist Destinations
- Firebase Authentication
- Cloud Firestore Integration
- AI Chatbot (under development)

## Technologies Used

- Kotlin
- Android Studio
- Firebase Authentication
- Cloud Firestore
- Firebase AI Logic

## Tourist Destinations

1. San Sebastian Cathedral
2. Casa de Segunda
3. Mount Malarayat
4. Milea Bee Farm

## Installation

1. Download the LipaGo APK.
2. Open the APK file on your Android device.
3. Install and launch LipaGo.
