# LipaGo

LipaGo is an Android mobile application designed to help users discover tourist destinations in Lipa City, Batangas.

## Features
- User Registration
- User Login and Logout
- User Dashboard
- Tourist Destinations
- Firebase Authentication
- Cloud Firestore Integration
- AI Chatbot (under development)

## Technologies Used
- Kotlin
- Android Studio
- Firebase Authentication
- Cloud Firestore
- Firebase AI Logic

## Tourist Destinations
1. San Sebastian Cathedral
2. Casa de Segunda
3. Mount Malarayat
4. Milea Bee Farm

## Project Information
**Project Name:** LipaGo  
**Platform:** Android  
**Programming Language:** Kotlin  
**Development Environment:** Android Studio

## Status
LipaGo is a student-developed Android application project. The AI chatbot is currently under development.
